# SCRIPTS

This repo contains useful scripts that I use for software development within my projects. Free free to use any of these scripts in your projects too.

## Instructions

```bash
# Fetch the file from the repo
$ curl -fsSL https://raw.githubusercontent.com/m-t-a97/scripts/main/<folder>/<script> -o <script> 

# Inspect the contents
$ cat <script>

# Make it executable
$ chmod +x <script>

# Run it (bash example)
$ ./<script>

# Run it (typescript example)
$ tsx/bun/node ./<script>.ts
```
